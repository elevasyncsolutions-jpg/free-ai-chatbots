# Contributing to AI Tools Directory

Thank you for your interest in contributing!

## How to Contribute

### 1. Suggest a Tool
- Open an issue with the "Suggest AI Tool" template
- Provide tool name, URL, and description
- We'll review and add it to our directory

### 2. Report Issues
- Found a broken link?
- Tool information outdated?
- Open an issue and let us know

### 3. Submit a PR
- Fork the repository
- Add your tool to the appropriate category
- Submit a pull request
